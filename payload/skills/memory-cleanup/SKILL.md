# Чистка памяти проекта

Память: `~/.claude/projects/<проект>/memory/`, индекс — `MEMORY.md`. Удалять и переписывать — только после согласия пользователя на конкретный план.

0. Потоки работы: открой `C:/Users/vi/.claude/skills/handoff/SKILL.md` и выполни его шаги до итоговой таблицы. Чистка идёт только после этого: свежее состояние уже записано в файлы потоков. Файлы потоков, обновлённые сегодня, в план удаления не включай.
1. Состояние: `python "C:/Users/vi/.claude/hooks/memory_cleanup_reminder.py" --status --cwd "<папка проекта>"` — в выводе число заметок и дата прошлой чистки.
2. Прочитай `MEMORY.md` и все заметки целиком (не по названиям). Для каждой отметь:
   - дубль или пересечение с другой — что с чем объединить;
   - устарела — факт из заметки сверяется с репозиторием (`git log`, `git grep`, чтение файла): факт не найден или противоречит текущему состоянию;
   - статусная заметка разрослась — оставить текущее состояние, историю сжать;
   - нет строки в индексе, или строка индекса ведёт на несуществующий файл;
   - заметка длиннее лимита (проект 50 строк, feedback 40, reference 90) или строка индекса длиннее 150 символов — сократить;
   - потоки `.claude/handoff/`: файлы со статусом `closed` и файлы без обновления 14+ дней внести в план («закрыть или оставить?»), удаляются только с «да»; статус и задачи, которые дублируют поток, из `project_*`-заметок убрать, оставив ссылку на поток.
3. План пользователю — таблица: заметка, что сделать (объединить / сократить / удалить / оставить), почему. Удаление и слияние — только с его «да».
4. Выполни согласованное. Слитые заметки: одна итоговая, ссылки `[[…]]` из других заметок перенаправь на неё.
5. Сверка индекса, ожидаемо 0 расхождений: каждая строка `MEMORY.md` ведёт на существующий файл, каждый файл заметки есть в `MEMORY.md`.
6. Отметь завершение: `python "C:/Users/vi/.claude/hooks/memory_cleanup_reminder.py" --done --cwd "<папка проекта>"` — в выводе `"due": false`.
7. Итог пользователю: было заметок → стало, что объединено и удалено.
